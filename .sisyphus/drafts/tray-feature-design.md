# MemFlow 托盘功能设计方案

## 产品定位分析

**MemFlow 核心理念**：
- 本地优先、隐私优先、极致性能
- 后台静默记录，不打扰用户
- 用户可随时控制录制状态
- 与 Cursor + MCP 集成，AI 能够感知用户上下文

---

## 方案 A：精简托盘（推荐）

### 设计目标
- 后台静默运行，最小化存在感
- 托盘图标显示录制状态（红点/绿点）
- 右键菜单提供核心控制功能
- 关闭窗口时自动最小化到托盘（不退出）

### 功能规格

#### 1. 窗口行为

| 操作 | 行为 |
|------|------|
| **点击关闭按钮** | 隐藏窗口到托盘，不退出应用 |
| **点击托盘图标** | 显示主窗口 |
| **双击托盘图标** | 显示/隐藏主窗口 |
| **启动应用** | 默认直接进入托盘模式（不显示窗口） |

#### 2. 托盘图标

**图标状态变化**：
- **未录制**: 灰色/静态图标
- **录制中**: 绿色 + 动画红点（眨眼效果）
- **已暂停**: 橙色图标
- **错误状态**: 红色图标

**Tooltip（悬停提示）**:
```
MemFlow
Status: [Recording/Idle]
OCR: [Running/Stopped]
```

#### 3. 右键菜单


#### 4. 通知提示（可选）

**事件通知**：
- **录制开始**: 静默启动，不通知
- **录制停止**: 可选通知
- **错误状态**: 弹出通知（如磁盘空间不足）
- **截图完成**: 静默，不通知
- **OCR 完成**: 静默，不通知

**通知设置**：
```
设置 → 通知
- [ ] 录制状态变化
- [ ] 错误警告
- [ ] 数据统计摘要（每日/每周）
```

## 技术实现要点

### Tauri 配置

需要在 `src-tauri/src/lib.rs` 中：

1. **启用托盘图标**（已有 TrayIconBuilder）
2. **设置窗口行为**（`set_window_skip_taskbar` + 监听关闭事件）
3. **托盘菜单项**（MenuBuilder）
4. **图标状态更新**（根据录制状态）
5. **双击托盘显示窗口**

### 关键 API

```rust
// 设置窗口不显示在任务栏
app.set_window_skip_taskbar(true)?;

// 监听窗口关闭事件
app.on_window_event(|event| match event {
  tauri::WindowEvent::CloseRequested { .. } => {
      // 阻止关闭，改为隐藏到托盘
      event.prevent_default();
      app.get_webview_window("main").unwrap().hide();
  }
  _ => {}
})?;

// 托盘菜单
TrayIconBuilder::new()
    .on_tray_icon_event(|app, event| match event {
      tauri::TrayIconEvent::Click {
          // 单击：显示/隐藏窗口
          let win = app.get_webview_window("main");
          if let Some(w) = win {
              if w.is_visible().unwrap_or(false) {
                  let _ = w.hide();
              } else {
                  let _ = w.show();
                  let _ = w.set_focus();
              }
          }
      }
      tauri::TrayIconListenerEvent::DoubleClick {
          // 双击：显示主窗口
          show_or_create_main_window(app);
      }
      _ => {}
    })
    .build(&app)?;
```
