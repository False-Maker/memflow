# Aider 命令参考

## 启动参数（aider --xxx）

| 参数 | 说明 |
|------|------|
| `--model MODEL` | 指定模型 |
| `--file FILE` | 指定要编辑的文件 |
| `--message / -m "提示"` | 单次提问后退出 |
| `--list-models 关键词` | 列出模型 |
| `--config / -c 文件` | 指定配置文件 |
| `--verbose / -v` | 详细输出 |
| `--commit` | 提交改动并退出 |
| `--test` | 运行测试并退出 |
| `--lint` | 执行 lint |
| `--help` | 帮助 |
| `--version` | 版本 |

---

## 聊天内斜杠命令（/xxx）

### 文件

| 命令 | 说明 |
|------|------|
| `/add 文件路径` | 添加文件到会话 |
| `/drop 文件` | 从会话中移除 |
| `/ls` | 列出会话中的文件 |
| `/read-only 文件` | 设为只读 |

### 编辑与模式

| 命令 | 说明 |
|------|------|
| `/code` | 代码修改模式 |
| `/ask` | 只问答不编辑 |
| `/edit` 或 `/editor` | 打开编辑器写提示 |
| `/architect` | Architect 模式 |

### 模型

| 命令 | 说明 |
|------|------|
| `/model 模型名` | 切换主模型 |
| `/models 关键词` | 搜索可用模型 |

### 运行与 Git

| 命令 | 说明 |
|------|------|
| `/run 命令` 或 `!命令` | 执行 shell 命令 |
| `/git 子命令` | 执行 git 命令 |
| `/commit` | 提交修改 |
| `/undo` | 撤销上次 aider 提交 |

### 上下文

| 命令 | 说明 |
|------|------|
| `/map` | 显示仓库结构 |
| `/map-refresh` | 刷新仓库映射 |
| `/context` | 查看 surrounding 代码 |
| `/tokens` | 查看 token 用量 |
| `/diff` | 显示变更 diff |

### 其他

| 命令 | 说明 |
|------|------|
| `/help` | 显示命令列表 |
| `/help 问题` | 根据文档回答 |
| `/clear` | 清空聊天记录 |
| `/reset` | 清空所有文件与历史 |
| `/exit` 或 `/quit` | 退出 aider |
| `/web URL` | 抓取网页内容 |
